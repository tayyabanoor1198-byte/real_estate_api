# 🏠 Real Estate Agency REST API

A full-stack Real Estate Agency project built with Node.js, Express.js, MongoDB Atlas and a responsive frontend.

## 🚀 Features

- User Registration
- Secure Password Hashing
- User Login
- JWT Authentication
- Admin/Staff Authorization
- Property Management
- Create Property
- Read Properties
- Update Property
- Delete Property
- MongoDB Atlas Database
- REST API
- Responsive Frontend
- Error Handling

## 🛠️ Technologies

- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- JWT
- bcryptjs
- HTML
- CSS
- JavaScript
